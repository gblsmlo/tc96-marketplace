# Storybook skills — three, one file each

The three split by **file**, not by mode of work — it is the only family in the vault
organized that way.

| Skill | Takes care of | Source | Internal support |
| --- | --- | --- | --- |
| `storybook-setup` | `.storybook/`, `vite.config.ts`, versions | [Storybook - Configuração e Builder](../../knowledge-base/storybook-configuracao-e-builder.md) | 5 references + 2 scripts |
| `storybook-story` | `*.stories.tsx` — the `meta`, the `args`, the tags | [Storybook - Stories e Args](../../knowledge-base/storybook-stories-e-args.md) | 5 references + 1 script |
| `storybook-test` | the `play` inside the story, mocking, a11y | [Storybook - Testes e Interações](../../knowledge-base/storybook-testes-e-interacoes.md) | 6 references + 1 script |

**Writing and reviewing sit together in each one**, because in Storybook the story **is** the test and
the decision is the same in both directions.

## The script that defines the family

`storybook-setup/scripts/descobrir-caminho.sh` — and the other two call it before
any prescription.

It reads the `framework` field in `.storybook/main.ts`, checks the version floors, and **looks
for the path contradiction in the code**:

| Under… | The mistake it finds | The symptom |
| --- | --- | --- |
| `react-vite` | `parameters.tanstack.*` | **no effect** — no error, no warning (`SB-RV-04`) |
| `tanstack-react` | a decorator with `RouterProvider` | a **second** router; the symptom appears far from the cause (`SB-TS-03`) |

**It is the only structure in the vault where prescribing the wrong path fails silently** — and
that is why it is the only one with a script whose job is to **discover before deciding**.

`SB-TS-*` and `SB-RV-*` are **mutually exclusive**: citing the wrong path's family is an
invalid finding. The ID map's header repeats that, and `storybook-test`'s `autoverificar.sh`
runs Step 0 **before** its own items.

## The ID map

Generated by `storybook-setup/scripts/gerar-mapa-de-ids.sh`, the same across the three: **75 IDs** in
nine families, with the whole of § 6.2 in the header — including the **pairs by path**
(`SB-TS-03`/`SB-RV-05`, `SB-TS-08`/`SB-RV-06`), which are **not** canonical and alias.

```bash
bash plugins/twincam-frontend/skills/storybook-setup/scripts/gerar-mapa-de-ids.sh
bash scripts/instalar.sh
```
